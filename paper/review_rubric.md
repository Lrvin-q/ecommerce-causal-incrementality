## 评分维度（每项 1–5 分，5 最好）

| 维度 | 评判要点 |
|---|---|
| **D1 学术严谨** | 假设是否讲清、有无过度声称、结论与证据是否匹配、是否区分"本文设定下成立"与"普遍成立" |
| **D2 因果识别** | 估计目标是否明确、识别策略是否成立、失效边界是否量化、是否混淆实现值与真值 |
| **D3 数值可信** | 数字能否追溯到结果表、区间与样本量是否给全、口径是否前后一致、单位与精度是否统一 |
| **D4 叙事逻辑** | 问题—方法—结果—讨论是否一条线；每节是否只做一件事；有无重复段落 |
| **D5 文字质量** | humanizer 规则：破折号、三段式排比、「不是X而是Y」、拔高意义、装饰性加粗、AI 高频词、自述文档结构 |
| **D6 图表** | 组图子图编号与可读性、图题是否陈述结论、表题与表体是否同页、坐标轴与单位、有无截断或重叠 |
| **D7 排版规范** | 公式编号右对齐、可跳转引用为蓝色、目录页码正确、无缺字、无溢出、图表编号连续 |
| **D8 诚实性** | 局限与失效条件是否具体可操作；是否主动报告"不好看"的结果；合成数据边界是否标注 |

## 五轮的关注重点（逐轮递进）

| 轮次 | 重点 | 允许提出的问题类型 |
|---|---|---|
| 第 1 轮 | **整体**：结构、论证链、过度声称、数字可信度 | 宏观问题，不必纠结排版 |
| 第 2 轮 | **因果识别与统计**：假设、区间、样本量、口径一致性 | 中观问题，逐条对照 CSV |
| 第 3 轮 | **文字**：按 humanizer 逐条扫描，挑出仍像机器写的段落 | 逐段给出「改前/改后」 |
| 第 4 轮 | **图表与排版**：逐页看图，子图可读性、题注、对齐、溢出 | 逐页逐图 |
| 第 5 轮 | **终审**：只看是否还有 blocking 问题；确认前四轮是否真的改到位 | 只报 blocking 与残留 |

## 输出格式（每轮统一）

```
## 本轮结论（是否可以进入下一轮：可以 / 有条件可以 / 不可以）
## 必须修改（Blocking，逐条：问题 → 证据（页码/图表号/CSV 列）→ 改法）
## 建议修改（按优先级，逐条同上）
## 做得好的地方（保留）
## 与上一轮相比的净变化（前一轮的 Blocking 是否真的解决了）
```

## 纪律

- 每条意见必须指向**具体位置**（页码、表号、图号、CSV 列名），不接受"建议加强论证"这类空话
- 必须实际渲染看图；看不清就说看不清
- 数字对不上必须点名
- 宁可尖锐，不要客套
- 不修改任何文件，只输出意见
