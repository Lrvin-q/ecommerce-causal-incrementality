# 结论与展望 {#ch-conclusion}

## 主要结论

本文围绕一次首单券的预算分配问题，构建了从数据生成、五表观测、因果估计到预算约束策略的完整链路，
并在正式重复实验上分别检验流程校准与决策层收益。结论有四条。

第一，流程校准是结论的前提，不是附属步骤。AA 校准在 1000 次零效应重复上给出合并假阳性率 0.046，
区间 [0.033871, 0.060884] 与名义水平 0.05 相容；区间下界低于预设带下沿这一事实同样保留在正文里。
没有这一层，"发现效应"就无法与"流程偏松"区分。

第二，在 F02 的场景、预算与策略规则下，定向发券相对不发券的收益方向可以被随机化验证复现：
200 个重复的点估计全部为正，196/200 在单侧 Holm 家族内通过；定向相对同预算随机在 190/200 通过。
同期"随机发券 − 不发券"的差均值只有 0.0675 元/人，区间跨零。
这组对照说明，在本文的设计里，收益主要来自"发给谁"的排序，而不是"发多少"本身。
按选模分层后，这一方向在四个学习器上一致，在常数策略层不能判定，
因此结论不能被选模频率改写成"定向普遍优于随机"。

第三，退款率护栏在 200/200 个重复内非劣效通过。它只说明数据不足以拒绝
"定向策略的退款率不比不发券差半个百分点以上"，不是退款风险为零的证明。

第四，两类重采样都保持方向，但都不能替代覆盖率证据。重训 bootstrap 重抽历史总体并重训模型，
四层的策略价值保持为正，通过率的层间差异由"定向优于同预算随机"这一主张决定；
固定策略 bootstrap 只重抽用户，四层中有两层的区间跨零。前者描述跨重复的离散程度，
后者描述单次实验内的抽样波动；两者不能互相替代，也不能相加，
都不构成覆盖率意义上的保证。

## 业务含义

如果要把这条链路用于真实预算分配，顺序应当是：先做 AA 校准与负对照，确认流程在零效应下不会误报；
再在独立用户总体上做小规模随机验证；最后才谈预算规模与策略迭代。
预算约束下，第一问不是"发多少"，而是"按什么顺序发"——没有排序的普惠发券，
在本文口径下不能稳定覆盖成本。护栏应当与收益主张同时判定，而不是事后再补。

## 局限

本文的结论受六条边界约束。其一，数据由已知生成过程合成，金额链路、效应结构与混淆机制都是设定的，
结论不能外推到真实业务。其二，F02 只在 L1 主场景、0.2 元/人的计划预算与固定贪心策略下验证，
换场景、换预算档或换策略规则都需要重跑。其三，每个重复独立选模，但策略搜索空间没有展开，
不能据此断言"贪心已是最优"。其四，重复间区间与逐重复区间回答不同问题，正文分开报告，不能混用。
其五，定向臂的真实支出高于预测约 5.6%，"同预算"指计划支出同预算，不是实付等支出。
其六，本文的 AA 是同设计的正式复跑，不是一份新的独立 AA 样本。

## 失效条件与对应证据

上节的六条边界不是免责声明，每一条都能在本文找到**会先亮红灯的位置**。把它们列成对照，
是为了让读者在迁移这套流程时知道该盯哪个指标：

| 失效条件 | 会在哪一步先暴露 | 本文的证据位置 |
|---|---|---|
| 流程在零效应下误报（分母、方差、多重性） | AA 校准的合并误报率 | 3.1 表 3-1 |
| 选模把聚合结论带走 | 按选模分层的配对比较 | 3.3 表 3-3 |
| 排序规则在不同估计模型下翻面 | 同 rep、同用户、同预算档的策略网格 | 3.4 图 3-2 |
| 响应面均值准但个体排序弱 | 校准与可达相关上界的对照 | 3.5 |
| 以预测成本核对预算而实际超支 | 真实与预测支出之比、超预算名单比例 | 3.4、3.5 |
| 重抽历史总体后结论翻面 | 重训 bootstrap 的逐层通过率 | 3.7 |
| 换一批用户后方向消失 | 用户层固定策略 bootstrap 的区间 | 3.8 |

## 后续工作

后续工作沿三个方向展开。第一，跨层重训与 Tier2 敏感性：检验上述方向在层间重训与精度下降时是否保持，
并把 Tier2 的数字单独报告，不与 Tier1 并列。第二，真实业务试点：以本文的校准、护栏与冻结顺序为模板，
先做 AA 与负对照，再做小规模随机验证，最后决定是否扩大预算。第三，长期效应与外部性：
本文的 30 天窗口不覆盖长期生命周期价值、网络溢出与竞争反应，这些需要单独设计。

## 结语

本文的贡献不在某个单点算法，而在一条可审计的链路：每个数字能回指证据表，
每个结论都带着它的失效条件。把这套流程迁移到真实业务之前，最重要的不是把数字做大，
而是保留 AA、护栏与冻结顺序这三道防线。
