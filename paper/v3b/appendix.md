# 附录

## 附录 A　四层机制的参数表

四层共用同一套业务量纲，区别只在于"哪一条假设被放松"。下表列出各层的机制开关与关键参数。

| 层 | 处理分配 | 结果方程 | 金额链路 | 时间结构 | 用于回答 |
|---|---|---|---|---|---|
| L0 | 与结果无关 | 效应同质、成本同质 | 单期 | 静态窗口 | 估计量本身是否无偏 |
| L1 | 与结果无关 | 效应异质、成本异质 | 购物车→首单→复购 | 静态窗口 | 异质性能否被辨识 |
| L2 | 与结果无关 | 效应可随时间漂移 | 同 L1 | 分周、按周拆分 | 结论的时间稳定性 |
| L3 | 依赖不可观测因子 $U$ | $U$ 经 logit 进入购买概率 | 同 L1 | 静态窗口 | 混淆强度的定量边界 |

金额链路的关键参数为：首单购物车比例服从均值 0.70、标准差 0.10 的截断正态（截断于 $(0,1]$）；复购在已转化用户中以 5% 的概率发生，金额为首单的 55%；券面额 10 元，只对首单生效，核销率 0.55；退款率基准 7.5%，发券臂乘 1.03，退款发生在 1 至 25 天内均匀分布。

## 附录 B　净贡献利润的账务口径

单用户净贡献利润由五项构成：收入、商品成本、履约成本、券成本与退款手续费。逐项口径如下。

| 项目 | 未退款订单 | 退款订单 |
|---|---|---|
| 收入 | 毛额计入 | 全额冲减为 0 |
| 商品成本 | 全额扣除 | 按 85% 回收 |
| 履约成本 | 全额扣除 | 刚性，不回收 |
| 券成本 | 核销则扣除面额 | **不退还，保留** |
| 手续费 | 不计 | 按毛额 1% 加收 |

退款订单保留在分析样本中，不剔除。GMV 按退款前的毛额统计，与净利润是两个指标，不能互相替代。

## 附录 D　预算口径与求解器的对照

三种预算口径的差别在"用什么替代尚未发生的核销"：

| 口径 | 成本口径 | 实际含义 | 实测超支概率（0.04 元/人档） |
|---|---|---|---|
| expected | 期望成本 | 按预测核销率折算 | 1.00 |
| buffered | 期望成本 + 缓冲 | 缓冲作用在预算上限 | 1.00 |
| worst_case_face | 面额上限 | 假设必然核销 | 0.00 |

五个求解器的主张范围：

| 求解器 | 能主张什么 | 不能主张什么 |
|---|---|---|
| 精确动态规划 | 分币粒度下的全局最优 | 面额连续时的最优 |
| 整数规划 | 同规模下的最优（与动态规划一致） | 大规模下的可行性 |
| 线性规划松弛 | 上界 | 可行解 |
| 贪心 | 近似解，近似比可分析 | 最优性 |
| 局部交换 | 贪心解的改进 | 最优性 |

## 附录 E　复现所需的实验条件

全部结果由固定随机种子生成，种子派生规则为：同一 `(master_seed, stream, index)` 三元组恒定对应同一串随机数，新增随机流不扰动已有流。正文中每个数字的重复次数 R 已在对应表格或图注中给出。

四层核心格各 500 次重复；二十个边界格各 30 次；零效应校准四层各 250 次；独立随机验证 200 次；模型对照 200 次；固定策略重采样 1000 次。样本量除标注外均为 200 000，分流比例 50/50。

运行环境为 Windows，Python 3.13，主要依赖 numpy 2.x、pandas 2.x、scipy、scikit-learn、LightGBM 与 EconML 0.17。全部计算在单机完成，峰值内存约 1.9 GB/进程，六进程并行。

## 附录 H　复现一份结果的步骤

1. 取得与本稿一致的源码与配置，安装依赖（`requirements.txt`）。
2. 生成总体：按场景标识与重复号调用总体生成器，样本量与附录 G 一致。
3. 取解析真值：调用真值接口，逐用户积分不可观测因子，得到期望净贡献利润；两个动作相减后取均值即为 ATE 真值。
4. 生成观测五表：按时间窗口与成熟规则固化结果，未成熟快照不进入主分析。
5. 估计：按场景要求的估计量计算 ATE、购买率效应与退款率效应；条件效应走五个候选模型，用验证集下界选模。
6. 策略：在测试集上按冻结的预算档与求解器生成名单，计算真实价值与支出。
7. 汇总：先逐重复计算，再跨重复平均；报告点估计、蒙特卡洛标准误与重复间标准差。

每一步的中间产物都可单独取出核对；正文中每个数字对应的重复次数与分母已在其所在表格或图注中给出。

## 附录 J　术语表

| 术语 | 本文的含义 |
|---|---|
| 净贡献利润 | 收入减退款冲减、商品成本、履约成本、券成本与退款手续费后的余额；未下单用户记 0，仍留在分母中 |
| 平均处理效应（ATE） | 全体用户的潜在结果之差在人群上的平均；本文的真值由数据生成过程解析给出 |
| 条件平均处理效应（CATE） | 给定可观测特征时的处理效应；策略排序用它，但其绝对水平不可靠 |
| 构成偏差 | 因处理组与对照组的用户构成不同而产生的偏差，与"未观测混淆"是两件事 |
| 设计 MDE | 在固定样本量、分流比例与检验水平下，能以给定功效检出的最小效应 |
| 盈亏平衡点 | 使净增量利润恰为零的购买率增量；本文为 3.47 个百分点 |
| 预算临界值 $B^{*}$ | 给每个用户都发券时的人均成本；本文为 0.83 元/人 |
| 非劣效界值 | 允许的最差损失上限；本文对退款率取 0.5 个百分点 |
| 单侧上界 | 点估计加 1.645 倍单次投放标准差；非劣效判定用它，不用重复均值的精度 |
| 分配人群口径 | 退款增量除以全部分配用户；回答"这个活动整体有没有推高退款" |
| 暴露人群口径 | 退款增量除以实际领券用户；回答"领券的用户风险有多大" |
| 选模后悔 | 被选中模型与事后最优模型的价值差；本文均值 0.019 元/人 |
| 固定策略重采样 | 冻结策略与模型、只重抽用户，用来看抽样波动 |
| 重训重采样 | 重抽总体并重训模型，用来看模型与选模的波动 |
| 桶宽 | 求解时面额离散步长；本文 0.1 元以内几乎无代价，1 元损失 14.2% |

## 附录 K　引用本文结论时的常见误用

| 误用 | 为什么错 | 正确读法 |
|---|---|---|
| 用 1.664 与 0.288 相减，说"混淆使利润虚高 1.38 元" | 两者不是同一标定下的同一个量；且 L3 的差距来自构成偏差，不是混淆 | L3 只读层内相对变化（+34%）；跨层不可比 |
| 说"护栏通过，有余量" | 全员口径的单侧上界 0.4964–0.4992，与界值 0.5 只差 0.001–0.004 | 前三层是擦线通过；换到领券人群口径直接越界 |
| 说"定向优于随机，所以模型有用" | 定向优于随机（+0.214）与模型优于业务规则（−0.054）是两件事 | 业务规则也优于随机；模型没跑赢规则 |
| 用 Tier2（R=30）的数字与 Tier1（R=500）排序 | 前者蒙特卡洛标准误约为后者的 4 倍 | Tier2 只读方向与量级，逐格标 R |
| 把"发券值得"的 0.98 当成商业结论 | 该判定成立的前提是效应为 5 个百分点；盈亏平衡是 3.48 | 先确认预期效应高于盈亏平衡点 |
| 用 B=10 042 元这类具体预算外推 | 预算档决定约束是否 binding，而 $B^{*}$ 是 0.83 元/人 | 先算 $B^{*}$，再判断约束是否起作用 |
| 把"平均效应无偏"当成"个体预测可用" | 个体排序相关系数只有 0.1025 | 平均无偏是个很弱的保证 |
| 认为成熟延迟格证明了"延迟无害" | 该格的机制开关未接入，它跑的是核心格 | 该格不构成任何证据 |
