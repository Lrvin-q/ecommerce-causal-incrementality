# Phase B 条件真值接口与精度门禁

> 合成数据 / 已知 DGP。机制验收说明，不是正式重复实验结果；最终运行证据见 `outputs/v3/validation/` 的带时刻独立目录和独立评审。

`generate_v3_population` 保存事实输入与 `audit_` 状态。`observation_bundle()` 仅投影用户、分配和事实订单；Phase C 还须建立路径及字段白名单，不能把这次投影当作完整防泄漏验收。`audit_conditional_truth` 与 `audit_realized_worlds` 均核对生成时的业务配置和数值配置哈希，拒绝跨版本拼接。独立验证人群要求显式传入策略臂及实际发券名单，不能沿用历史处理分配伪造策略随机验证。

## 目标与误差传播

利润真值按整数分记账机制，对未实现的购买、金额、核销、退款、复购和时间截窗求期望。L3 进一步积分不可观测 U，模型主审计目标为 `cate_profit=E[Π(1)−Π(0)|X]`；`cate_profit_xu` 仅为条件信息更丰富的另一审计目标。个体实现世界差不代替任一条件期望。

金额模块对分币求和、时间积分、履约尾截断、基本浮点操作及特殊函数交叉复核分别给出元单位诊断。CATE 先合并两动作共享组件的系数再求和，降低接近零时两大数相减的误差。逐用户 U 概率误差乘上相应利润敏感度，并保留与金额核误差的乘积项：若 p1=p0+(1−p0)h，每次购买利润为 A0、A1，则共用 U 积分的 CATE 敏感度为 |(1−h)A1−A0|。

逐臂利润和 CATE 都检查绝对误差估计≤1e−6元且相对误差估计≤1e−6。目标恰为零时相对误差没有定义，明确保存 NA 和 `*_relative_error_defined=false`，只检绝对误差；不能将此行描述成相对精度已获证明。近零非零目标仍执行双门禁，不按绝对精度单独放行。

L3 的默认批积分未通过利润门禁时，仅对失败行进行完整支持上的自适应积分，再检查一次。仍失败则抛异常。逐行保存方法来源、是否精化、误差分项和阈值；不把失败行删除，也不修改精度阈值。

## 证据的适用范围

总体数值误差是诊断估计，不是区间算术认证的严格上下界。尾截断与基本浮点运算部分具有对应数学界；QUADPACK 误差、相邻节点差和 CDF 交叉复核仍依赖数值算法的适用条件。测试将时间积分容差额外收紧到1e−14时触发舍入告警，该结果仅作收敛差异对照，不能宣称达到请求的1e−14。默认生产时间积分请求1e−13。

独立 MC 使用拒绝采样 Q、另写的 Gamma/Uniform 时间和整数账务实现。按已冻结参数依据，判据为 max(0.001元,4×MC_SE)，并保存真实误差与 MC_SE；这不等于所有 MC 差异都小于0.001元。统计抽样误差、确定性数值诊断和分币恒等式分别报告。

L0 两个人工控制保留不可行用户的自然机制，并报告全体、各自可行域及共同可行域。可行子集的同质残差门槛仍是冻结的0.001元/人，与积分精度门槛是不同对象；不能用一个门槛替代另一个。

首轮机制校验发现，技术ID `L0_Pi_heterogeneous_cost` 对应的自然核销成本，在利润控制的共同可行域内几乎相同：固定购买率、核销率和10元封顶，使较高购物车用户几乎都抵满券额。因此后续表图采用“自然成本机制”标签，保留实际成本分布；不得将该格称作已经构造出实质成本异质性，也不得据两格差异证明成本筛选价值。两格当前主要体现成本水平差异。固定矩阵不因结果不理想而调参；效应筛选和成本筛选的结果需在 Phase E 按实际成本分布解释，若未来另研究强异质成本，应作为事前版本化扩展。

## 回归证据

`tests/test_v3_engine.py` 包含业务/数值版本错配拒绝、注入过大金额误差必须失败、只精化失败行等集成测试。金额模块另外构造1e−5与1e−7元的近零 CATE 检查双门禁。更接近零的效果可能超出当前精度能力，此时必须失败或另行实现更高精度计算，不能把生产校验成功外推到所有极端参数。
