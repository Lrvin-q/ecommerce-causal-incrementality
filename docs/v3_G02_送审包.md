## 4. 评审必须盯的四个边界（已写进正文，请核对是否处处一致）

1. **四层同属一个 DGP 家族的层水平偏移，不能当四份独立证据平均**，也不给"跨层总通过率"。
2. **L0 的低决策通过率不是"策略价值为负"**：它卡在"定向优于同预算随机"这条主张上，与 3.2 的读法一致。
3. **"通过率"是跨 b 的描述性统计，不是验收阈值**；判定发生在每个 b 内部。
4. **本阶段不声称"定向有效"**，也不声称策略可部署；与 F01/F02 的边界措辞一致。
