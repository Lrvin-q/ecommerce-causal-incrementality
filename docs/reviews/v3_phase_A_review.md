## 带入 Phase B 及后续阶段的强制门禁

- 按最终协议执行已明确的 RMSE 条件信息集。清洁完整 X 的机制目标作为审计诊断时，不得将缺失信息导致的不可约误差全部称为模型学习误差。
- L0 同质子集成员若依赖隔离真值，只能在冻结后的子集审计中使用；不得通过名单资格字段向学习或策略侧泄漏。
- 分币金额、30 天内事件/30 天后退款、入库延迟与复购时间必须同时进入真值核算；自然机制下的期望不等于将全部最终退款计入 30 天。
- Phase A 通过只授权进入机制实现，不表示以上约束已在代码中实现，也不表示正式结果已完成。
- B 必须实际证明分币真值积分、时间截窗、L0 合法概率和数值同质可行域、等成本真实核销机制、噪声均值固定/方差变化、L3 固定扫描真值不变及可观测性；失败须保留，不得为通过而改目标或裁概率。
- C 必须检验所有正式格都经过五表/污染清洗/SQL，训练变换不偷看测试，L3 完整共同原因能从观测 W 恢复，真值区和同质子集成员不能反流模型侧。
- D 前按冻结要求完成每类20次 pilot 并外推全部任务；D/F 用实际臂人数与成熟窗口，核对 PSM 目标、Holm 决策家族、成本区间、随机验证未支持与真实有害的区别。
- 这些是已冻结范围的后续验收条件，不是放行任何未修 Phase A 缺陷；任一语义变更须保留原哈希、理由、影响范围并重新审查。
