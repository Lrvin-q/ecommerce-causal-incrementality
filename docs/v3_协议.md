## 1 决策卡

模拟平台营销团队在用户符合“加购未支付”资格、观察窗口开始前，依据分配时可见信息，决定是否给一张10元首单券。在相同人均预期核销预算下，提高全体合格用户30天净贡献利润，同时检验退款事件率的预设非劣效界值。误推荐、误拒绝、预算超支、退款风险分别记录。

单位为用户，主指标为相对不发券的净增量贡献利润（元/合格用户）。7天支付购买率、订单总额GMV、退款后净交易额、消费者实付和核销成本分别命名。退款订单保留，零单用户利润组件为零。购买率是诊断指标；禁止又把它称为共同主指标。

本轮不做多面额优化、DID实证、网络溢出、长期LTV。DID的未受干预对照、可检验平行趋势、明确时点条件须在报告逐条讨论。既有随机或观察性数据不自动赋予DID可解释性。

## 2 金额、退款与目标量

### 2.1 金额链路

Q来自N(0.7,0.1²)在(0,1]内的条件分布，不做上限裁剪。首单G1=CQ，第二单G2=0.55G1；首单发生且复购条件满足才产生第二单。复购概率保持0.05，第二单不带券。其他变动须成为显式场景覆盖。

存储单位为整数分。C先向下取整到分；G1向下取整到分，保证G1≤C；G2对0.55G1按half-up舍入到分，误差≤半分。实际核销抵扣D=min(1000分,G1)；未发券/未购买/未核销时D=0。商品成本、回收成本、手续费按配置次序逐单舍入。真值必须对应同一舍入机制；未舍入近似须给误差界，不能称完全精确。

### 2.2 经营账务真值表

保留旧机制的“券前商品总额+独立促销成本”经营账。G为商品总额、D为核销抵扣、g为商品成本率、h为退款可回收比例、F为履约成本、f为退款手续费率。消费者实付G−D单列；退款商品总额按G冲减，消费者退款G−D另列。券不退回表示促销结算成本不回收，退券是显式配置。

| 核销 | 退款 | 商品总额冲减 | 商品成本回收 | 券成本（不退券） | 净贡献 |
|---|---|---|---|---|---|
| 否 | 否 | 0 | 0 | 0 | G−gG−F |
| 是 | 否 | 0 | 0 | D | G−gG−F−D |
| 否 | 是 | G | hgG | 0 | −(1−h)gG−F−fG |
| 是 | 是 | G | hgG | D | −(1−h)gG−F−fG−D |

这是模拟的经营预算假设，不是完整平台/商家合并现金流报表。保持退款后的沉没促销成本，不能为了同质化悄悄取消。退券时最后格D归零。GMV、净交易额、利润三者不混称收入。消费者实付不能作为再次扣D的利润起点。SQL与独立数组账务逐组件对账，先制定上表再实现。

### 2.3 目标

τΠ(X)=E[Π(1)−Π(0)|X]；L3另保留τΠ(X,U)仅供审计。X-only模型RMSE必须对积分后的τΠ(X)。V_inc(π)=E[π(X)τΠ(X)]，不再减券。R_net=NV_inc/C_coupon为已扣券净增量/券预算，0<R_net<1依然正净增量。

总体均值、条件于当前X的有限总体价值、随机实现值和学习流程平均值分别标识。同评估样本策略差采用配对区间并保留协方差。预测目标上的LP上界/求解gap与真实利润regret不同名。

## 3 场景与机制

`configs/v3/scenarios.yaml`是唯一机器清单，参数理由在`docs/v3_参数依据.md`。导出表逐行含稳定ID、level、tier、n、分流、配对族、覆盖参数、模型、R、状态；格数由注册表计算，不手抄。每rep的模型共享数据和拆分，配对场景共享应固定的随机流。

### 3.1 L0

Tier1主场景L0-P：购买概率增量同质，允许金额诱导利润异质。L0-Π为独立等成本/异质成本控制格；先输出合法购买概率可实现的效应区间，再用仅该场景存在的κ(X)校准。全链标注“同质化旋钮（control knob，非业务机制）”，报告范围、分布、触发/不可行比例和子集差异。不可通过概率裁剪伪造恒定效应。

等期望成本控制须由真实核销机制实现，不能只给优化器常数成本；校准核销概率不可行时输出子集，不clip后仍称等成本。购买零增量但发券有成本不是利润AA。真正AA在相同处理条件下用虚拟标签比较，完整经过五表、污染清洗、SQL。

分币舍入使毛利率到期望利润的关系分段，不能将其称为精确线性方程。先解未舍入解析候选，再按记账机制数值求解和检查预置残差容差；不满足则标记不可行。两成本对照的共同可行子集只在冻结后审计中选择，不作为学习资格泄漏。

### 3.2 L1

主实验20万人，训练10万/验证4万/测试6万，用户隔离。常数/T/S/CF共享数据正式比较，按正文增加DR-learner。选择只用观测验证指标，不用审计RMSE；公式与阈值在配置冻结。学习曲线、信号/异质性、错设、MAR、金额比例、成本误差逐格列出。Q2排除旧纲领的券面额扫描，显式记录范围差异，不声称验证面额稳健性。

独立信噪对照固定X和条件均值，改变履约成本噪声，校准下限裁剪及逐分舍入后的均值。B阶段必须证明条件均值/ATE不漂移而条件方差变化；不能只用配置SD宣称扰动生效。不向X加测量噪声。MAR、截尾和删减特征使学习所见W不同于完整X；对τ(完整X)的RMSE明确称“端到端机制恢复误差”，包含信息损失，不全称模型学习误差。W分组的观测DR校准和观测风险回答可学习表现；任何声称剔除了信息损失的学习误差必须另求E[τ|W]，不能偷换条件集。

### 3.3 L2

人数3万/6万/10万/20万×处理比例0.5/0.3/0.1完整交叉。无漂移/平滑/突变、构成变化分别比较并有预定联合压力格。延迟与未成熟误用是诊断对照，正式评估只用利润成熟样本。

周次进入真实分配时间。前期训、中期验、后期测；滚动起点只读当时已成熟训练数据。静态无时间、含时间特征、滚动重训分别比较。报告逐周ATE、指定目标人群加权ATE、错误混合对照。标准误按真实用户/时间依赖选择，不凭空添加共同时间冲击。

### 3.4 L3

固定λY、X/U、潜在结果，仅扫λT七点，分配截距校准保持比例。λT=λY联合七点另标“ATE变化”。Logistic/正态/有界U匹配均值方差，范围和尾部不匹配须报告。重叠压力改变可观测分配强度，独立于隐藏混淆。

主扫描、联合/重叠/U分布对照保留完整可观测混淆特征（缺失与异常金额污染为零，不截尾/裁剪特征），标准化保持可逆；事件重复和入库延迟仍走污染/清洗/SQL。否则即使λT=0，丢失的购物车真值也会成为W条件下的隐藏共同原因。另设`L3_missing_confounders`外围配对格恢复MAR/异常值/截尾，专门研究此信息损失，不能用它冒充可忽略性成立的方法基准。

Naive/IPW/DR针对总体ATE；PSM明确匹配处理人群ATT并对同一人群真值审计。真实e(X,U)只在审计区；X-only目标积分U。先核对无隐藏混淆基准的目标和标准误，再解释失效。独立随机策略验证给出另一识别来源，DR名称不代表可解决隐藏混淆。

## 4 数据与真值隔离

`data/v3/<level>/<scenario>/rep_<id>/`保存raw、污染或无损差量、clean五表、SQL观测分析及manifest；真值另写`audit/v3/.../truth/`。代表rep完整SQLite/CSV，其余正式rep至少保压缩五表/无损差量、SQL结果、manifest，不能只保种子声称执行了工程链。

主键run_id+实体ID。设计概率可观测，L3真实倾向不可观测。学习接口只接受ObservedDataset白名单，拒绝audit路径、U、潜在结果和truth列。填补/截尾/特征变换仅在训练拟合；记录污染及修复，不删退款或失败重复。

冻结manifest含模型hash、配置hash、预算、阈值、预处理、观测选模指标和时间。OPE/随机验证结果冻结后才解封审计。集成测试主动注入真值列、路径和未冻结策略必须抛错。审计结果不反流同rep选模。

独立验证每rep另生成20万人，预定不发/同预算随机/定向策略臂，分母为全部入臂用户，按相同人均预算。保留分臂/发券名单、汇总、manifest；代表rep完整五表。核销/退款/复购与历史随机流独立。

## 5 检测与观测评估

MDE按真实总量、训练/测试、验证臂反解，报告购买率和利润80%/90%功效，单项和预定检验家族校正后的能力。利润方差来自独立pilot，不读最终测试真值设阈值。唯一主指标利润；购买率是诊断。

完整AA和微观局部效应功效走五表SQL。局部效应由合法购买机制参数产生，不向实现利润加常数。护栏为30天任一订单退款的用户级事件率，预置绝对界值和单侧区间，购买者条件比例仅描述。

IPW/DR/归一化对照均实现；nuisance交叉拟合，每条结果不参与自身残差模型拟合。随机日志用设计概率，观察日志估计e(X)并声明假设。无重叠/ESS不足按预设规则拒绝可靠评估。配对差同时估计利润、核销成本和护栏；固定策略区间、重训分布、名单波动、MC误差分开。

价值证据、成本和护栏共同决定建议，不在结果出来后换门槛。L3历史OPE依赖不可检验假设，独立随机验证为模拟确认，不能写真实平台业绩。错误推荐与错误拒绝分别报告。

“值得发券”检验定向对不发券净增量；“定向优于随机”检验同预算配对差。预设两比较家族采用Holm，护栏与可靠性参与门槛，详细判定表在evaluation.yaml。主推荐只指进入模拟随机验证的候选，要求预测期望预算可行；若观测成本下置信界已超过预算则拒绝，区间跨预算标为预算不确定，不承诺支出上限。超支概率为报告量，不擅加用户未要求的10%硬约束。随机验证未通过只称“未支持”，不是已证明真实有害。代表rep的预算专题区分预期成本、保守预测成本和最坏面额上限，分母均为全体目标用户。

## 6 优化

比较不发、全量（标预算可行性）、随机、业务规则、购买倾向、预测利润、预测增量、增量/成本贪心、贪心局部交换。小规模分币精确DP/MILP/穷举互证，成本桶宽逐级收敛，规模-精度-耗时并报。大规模仅有可行解时配LP/MILP界，未证最优不得写最优。

成本预测E[实际核销支出|X,发券]含购买、核销、封顶、退券。预期预算不保证实际硬上限，报告超支概率及保守/最坏面额控制对照。测试名单只用X和冻结规则；真值策略只在审计，不是可部署方案。
