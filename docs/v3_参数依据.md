## 1. 证据分级与配置合并

本次没有取得企业历史日志或外部参数估计。旧 `configs/base.yaml` 中“行业通常”“平台现行”“历史核销率”等未附原始证据的语句，不作为经验事实继承。下表中“继承”仅表示继承 v2 的模拟假设或实现选项，绝不表示经过现实数据校准。截距校准命中一个模拟目标，也不构成目标本身有经验依据。

配置分为七份，合并后形成一个根对象；同名根键不得互相覆盖。所有 scenario 的 `overrides` 是指向合并对象的点分路径，未知路径必须报错；`n` 与 `treatment_probability` 是逐格最终设计元数据，优先于全局设计默认值。运行前保存所有七份文件、展开后的配置和哈希。调试、pilot 与正式运行分别使用 `v3_debug`、`v3_pilot`、`v3` 路径，不能合并汇总。

| 文件 | 职责 | 依据性质 |
|---|---|---|
| `business.yaml` | 金额、账务、窗口、人口与数据污染 | 用户裁决 + 明示模拟假设 |
| `scenarios.yaml` | DGP 旋钮、每个完整场景及功效设计作业 | HITL §2、§4、§8 的有限实现清单 |
| `design.yaml` | 固定资源MDE、拆分、AA、护栏、时间可见性 | 预设统计设计；风险界值是容忍情景 |
| `models.yaml` | 四共同模型、L1/L3 的 DR-learner、观测估计 | 方法配置，不预设优胜者 |
| `policy.yaml` | 预算、策略、成本预测、求解精度 | 模拟决策情景与计算比较设计 |
| `evaluation.yaml` | OPE、验证、区间、真值审计、报告 | HITL §6 规定与预设诊断规则 |

全部金额参数单位为元（CNY），落账为整数分；率/占比为0到1的比例，绝对率差为概率点，0.005就是0.5个百分点；模型线性系数为无量纲 logit 单位；样本、树数、折数、种子数、迭代次数是计数；时间以字段注明的天/周/小时/秒为准。时间系数和噪声乘子无量纲。源码实现不能通过另写常数替代配置。

| 商品成本率 | 0.68 | 继承假设，基数为券前订单总额 |
| 履约均值目标、原始标准差、下限 | 5、1.2、0.5元 | 保留下限裁剪正态族，反解原始位置使裁剪及分币后均值为5；实际标准差另报 |
| 可回收商品成本比例 | 0.85 | 继承假设；退款仍留15%商品损耗 |
| 退款手续费率 | 0.01 | 继承假设；按券前订单总额计算 |
| 退款后券成本 | 保留 | 继承既有经营核算约定，不能默改为退还 |
| 窗口 | 购买7天，利润30天 | 原业务纲领；所有用户相对各自分配时间等长 |

金额按以下顺序入账：真实购物车先向下取整到分；首单金额为已分币购物车乘Q再向下取整到分；第二单为首单分币金额的55%，采用 decimal half-up 到分。商品成本、履约成本、回收成本、手续费各自按约定 half-up 一次；不把已经舍入的合计再拆分重算。首单不得超过购物车；第二单相对55%的误差最多0.5分；券抵扣取10元与首单总额的较小者。零分极小订单的可能性必须由边界测试涵盖，不能额外添加抬高首单金额的最小客单价。

主经营账采用券前总额G入账，券补贴D单列扣一次；消费者实付G−D另列。退款时消费者退款为G−D，经营账冲减G，券补贴D仍保留，商品成本只回收85%，履约不回收，手续费另列。这是刻意保留的经营核算口径，不能宣传为平台与消费者之间的合并现金流恒等式。

设K是商品成本、F是履约、H是手续费，表中量均按每笔订单的已记账分币值计算：

| 是否核销 | 是否退款 | 消费者实付/退款 | 经营账净贡献 |
|---|---|---|---|
| 否 | 否 | G / 0 | G−K−F |
| 是 | 否 | G−D / 0 | G−K−F−D |
| 否 | 是 | G / G | −K+回收K−F−H |
| 是 | 是 | G−D / G−D | −K+回收K−F−D−H |

退款、低金额及人工控制均可能出现单笔负利润，配置明确允许；禁止将负利润截断为零或删除退款单。未购买用户净利润和券成本均为零。GMV是券前订单总额之和，退款后净交易额与净贡献利润分开命名。

首单延迟沿用 Gamma(shape=2, scale=1天)，截在[0.05,6.95]天；退款延迟沿用下单后 Uniform(1,25天)；复购延迟沿用相对首单的 Gamma(shape=6, scale=1.5天)，截在[1,25]天。延迟参数原先写在代码里，本次移入配置。只把事件时间处于分配后30天内的交易/退款计入30天目标；跨窗事件保留，但不偷渡进窗口。解析真值必须同时积分金额、核销、退款、复购及时间截窗，不能只替换平均首单金额便沿用旧公式。

解析真值应与上述分币顺序相同。可以按金额分段概率对分币账求和，或采用有明确误差界的积分方法；无证明不能把未舍入真值冒充落账真值。积分目标绝对/相对误差均为1e−6；独立高精度MC校验报告SE，比较容限为 max(0.001元,4×MC_SE)，并报告实际误差，不能反选随机种子。

## 4. L0 同质化与等成本控制

L0-P是Tier 1主场景。L0-Π两个Tier 2控制场景保留购物车金额链路，目标利润CATE为0.50元/人。这是控制目标，既不是v3结果也不是盈利门槛。

首先固定自然商品成本率，计算仅改变合法购买概率时可达到的利润范围并报告可行比例；对无法达到目标的用户不得裁剪概率后继续称同质。然后尝试显式同质化旋钮κ(X)：把有效商品成本率改为依赖X的解，等价毛利率限制在[.02,.98]。该旋钮同时作用同一用户两种处理状态下的首单和复购商品成本，退款回收也沿用相同有效成本率；求解须包括全部退款、时间及舍入规则。自然成本率0.68作为无可行解时的保留值。

等成本控制进一步设目标 c(X)=0.50元/被发券用户，求

`核销概率(X)=0.50 / {p1(X) × E[min(10,G1)|X]}`。

它是独立于同质化旋钮的实验成本控制，同样是人造机制。分母不足0.50或核销概率不在[0,1]时，标记不可行；不能裁到1后仍声称等成本。自然成本场景维持核销率0.55，允许c(X)变化。等成本/异质成本比较用两边利润同质域与成本可行域的交集；全体样本照样保留，额外给出交集与全体的差异。不得只展示更漂亮的子集。

分币后目标函数可能为阶梯，不能把未舍入公式的线性解当成最终解。冻结求解为有界单调阶梯函数的数值括区搜索，最多200次、参数区间容差1e−10；利润同质误差容限0.001元/人。没有达到此容限的合法值就记不可行，不裁剪目标或偷偷放宽。报告最大绝对残差与子集CATE范围，注明“数值容限内同质”。

必报购买概率单独可行率、最终共同可行率、κ分位数、旋钮触发比例、子集/全体特征差异和全体/子集结果。如果全部用户不可同质就明确说“只在子集上同质”，而非“已实现全体同质”。负利润在此控制场景也明确允许。真实CATE恒定或仅有约定数值残差的子集，其相关系数、R²、top排名真值指标记NA，并展示残差本身，不能强造排名。

## 5. L2 的日历、样本与迁移

样本量3万/6万/10万/20万与处理概率.50/.30/.10完整交叉，共12格；20万×.50为Tier 1，其余11格R=100。固定潜在生成流并用前缀用户比较不同n，分配另用配对随机流。

L2按日历周[1,2,3,4,5,10,11,16,22,28]入组，每活跃周占10%。前五周训练，10/11周验证，16/22/28周测试，保持50%/20%/30%人数。间隔是明确的设计选择，用于30天利润成熟和延迟入库；不是假称连续三周已经获得30天利润。逐周数据仍以真实分配时间生成。首个未来起点前训练和验证均须完全可见；后续滚动起点可纳入以前测试周已经成熟的用户，但不得将当前或未来用户的标签提前读入。用户只能首次入组一次。

每个L2场景比较静态、不重训但含时间特征、按起点滚动重训三种模式，四模型在每种模式都执行完整R。静态模式不读时间特征；后两种模式可读分配时已经确定的 assignment_week 和 assignment_elapsed_days，不得读结果成熟与否等未来信息。平滑效应倍数依次为1.6/1.5/1.4/1.3/1.2/1.0/.9/.7/.6/.5；突变为前五周1.6、中两周1.0、后三周.6。人群变化单独把新客占比由.30改到.45/.60，推荐渠道由.30改到.40/.50，同时搜索由.35降到.25/.15，其余渠道不变。均是预设压力假设，不预设衰减或重训一定造成哪种结果。

另列效应漂移×构成变化的联合格、168小时入库延迟格、7天未成熟快照误用格。最后一个同时保存成熟主分析；错误快照不能代替成熟结果。按周、固定参考人群加权、错误合并对照和未来期价值分别报告，不能只给混合误差棒。区间以用户为基本聚类，另做长度为2个活跃队列的时间块敏感性；活跃时间块少的限制须披露。

## 6. L3 双旋钮、重叠与U分布

L3主比较的识别前提是分配所用的所有可观测共同原因确实完整留在学习器输入W中。固定真值、联合、重叠和U分布各格统一将购物车MAR缺失率全部置0、历史GMV异常污染率置0、winsor分位改为[0,1]、标准化截断改为null，仅允许可逆标准化。入库延迟、重复日志及五表/清洗/SQL链路仍执行。所有分配预测量须能由W恢复；不能在分配时使用记账舍入前的潜在连续特征、随后却只给学习器舍入值。于是lambda_T=0时U虽能影响结果，但不影响处理分配，可作为仅可观测混淆的校准基准。

新增Tier 2场景 `L3_missing_confounders`，与 `L3_fixed_lt000` 共用潜在机制及分配随机流，只恢复原MAR率(.02/.04/.12/.08)、异常污染率.002、winsor[.005,.995]和z值±3截断。该格n=200000、ATE/五模型完整学习/独立随机验证均R=100。即使lambda_T=0，分配仍依赖未完整观测的true X，给定W的可忽略性也没有保证；此格用于信息损失导致的残余混淆压力研究，不能用于“无隐藏混淆”方法校准。L3真正AA保留原污染，因为虚拟标签独立随机、两个标签实际动作相同；它检验零标签效应的工程链路，不能替代观察性可忽略性校准。

固定真值七点扫描 λT∈{0,.25,.50,.75,1,1.25,1.50}，λY=.50，λT=0为Tier 1。每次配对重复的X、U、购买/金额/退款/复购潜在机制完全共享，仅重分配T；逐格反解分配截距，使平均设计概率保持.50。这不消除隐藏混淆，只是控制处理比例。

联合七点令λT=λY，明确总体真值可以变化。可观测分配斜率另乘.25、2、4且λT=0，单独研究重叠；再加一格λT=.50且斜率×4的联合压力。原始估计概率分布、截断前后权重、ESS、被截断比例都保留。

U三分布是标准化Logistic、N(0,1)、Uniform(−√3,√3)，理论均值均0、方差均1。Logistic原始scale=1再乘√3/π。两种无界分布与有界分布不可能同时匹配支持集，因此明确报告支持差异及每rep经验均值/方差/极值/1%和99%分位；不把支持差异隐去。分布比较共用均匀变量经各自逆CDF生成，与固定扫描的λT=.50 Logistic格配对。

学习器使用观测X，CATE真值对U积分；不以条件于(X,U)的效应替代。PSM目标是实际匹配成功处理人群的ATT，给匹配后人群真值与匹配率，不和总体ATE硬比；匹配复用方差不能使用普通样本bootstrap冒充。λT=0仍有可观测选择，若该基准的目标/标准误不正确，后续混淆结论不能出稿。

## 7. 模型、策略、预算与诊断阈值

共同模型是常数、T、S、CF；L1和L3额外DR-learner，不能因Tier表写“四模型”而省去正文要求的DR。LightGBM沿用300树、学习率.05、31叶、最少40样本、行/列采样.8；CF沿用300树、叶最少60、3折，二元处理第一阶段使用分类器；所有模型内部只用1线程。它们是初始冻结超参，不声称达到真实任务最优。

模型/策略选择仅使用验证观测数据的交叉拟合DR净价值下置信限，成本模型只在训练拟合、验证校准。L1学习曲线训练人数10k/25k/50k/100k，后两部分仍固定40k/60k；不用缩小测试集制造学习曲线。

预算为0.04/.10/.20/.30/.40/.60/.80/1.00元/全部目标用户，主预算0.20元；总预算=人均预算×目标人数，避免真值成本进入预算定义。该序列是冻结的模拟资源情景，不沿用旧“预算/人数=利润盈亏平衡”的错误解释。这里只保证预测期望成本约束，实际超支概率另报；全量发券作为无预算约束参考，不能混成同预算可行策略。

除不发券、全量、同预算随机外，预设新客优先再购物车排序的业务规则、购买倾向、预测利润、预测增量、增量/成本贪心及局部交换。完整求解专题在每场景代表rep的所有预算点执行：小规模20/100/500人比较分币DP、MILP与LP；500人做1/.50/.10/.05/.01元桶宽收敛；1000/5000/全测试规模做限时60秒MILP并保留上下界、gap、状态。只有求解证明对应问题最优才可称最优；分币化原问题与连续预测成本问题不是同一目标，须分别标明。

各完整rep均执行贪心、局部交换和同目标同成本LP；上述完整规模专题是逐场景代表rep，不冒称每rep都运行大规模MILP。小反例成本[6,5,5]、利润[12,9,9]、预算10来自业务方案，只用于方法实现核验。优化gap与真值regret分开。

策略验证采用额外20万人，三个政策臂为不发券/同预算随机/已冻结的选定定向策略，约各三分之一（实际整数臂人数记录），主预算0.20元/各臂全部分配用户。其他预算在独立历史测试OPE和真值审计中扫描，不能声称也分别做了随机策略试验。OPE用IPW、DR、分别归一化处理/对照项的SNIPS；跨拟合3折；成对差值保留协方差。

可靠性阈值为每动作ESS≥200且≥动作样本数5%、支持违规比例≤1%、概率支持[.01,.99]。这些是先验模拟决策规则，没有行业背书；结果需另报连续诊断量，不能把“过阈值”直接写成已识别。费用、退款、置信下限、预算可行与可靠性一起构成推荐门槛。净利润推荐门槛0元/人只表达正净增量；回报小于1不等于亏钱。

MAR缺失、填补与winsor会使学习器实际看到W而非完整真实X。主机制审计RMSE字段命名为 `mechanism_cate_rmse_end_to_end`：预测是W的函数，目标是真实X条件下并对U积分的CATE，它包含信息损失和模型误差，不能全部解释为纯学习误差。可学习表现通过按观测W/冻结预测分组的DR校准及独立观测策略风险评价；若以后声称纯模型RMSE，须另实现对缺失/粗化真实X给定W的条件积分。

保守预算对照在每层Tier 1代表rep、全部8预算点执行：冻结预测成本乘1.25作为明确缓冲（不保证硬上限）；另一对照每个发券用户按最坏10元记预算，只发 floor(B/10) 人以内，利用真实抵扣不超过面额保证券支出不越预算。每个对照仍比随机/贪心/局部交换并使用200随机种子，报告价值、成本区间和超支风险；这不是只写一个 hard_cap=false 的口头声明。

最终输出两项分开的判断：定向相对不发券是否值得发券、定向相对同预算随机是否具有优势。两项使用同一单侧α=.05的Holm比较族，区间由相同族检验反演，不能拿未校正CI代替；推荐候选需第一项通过，宣称定向优势需第二项也通过。推荐只表示进入模拟随机验证的候选，不是实际部署。主预算约束仍为冻结预测期望成本不高于B；收益、护栏与可靠性还须通过。观测DR成本给95%区间：下界已高于B则拒绝，区间跨B则标记预算不确定，不能承诺成本上限；区间跨B本身不剥夺进入随机验证的资格。超支概率及其MC精度只作为报告和敏感性量，不另加10%风险门槛，也不强制成本UCB≤B。仅依观测成本的风险预测bootstrap在每个完整rep的选定策略主预算上做1000次；不把全部8预算、全部策略都扩成额外风险bootstrap。保守和最坏面额预算仍按代表rep专题执行。

## 9. 参数敏感性与 Q2 的裁决覆盖

原业务纲领要求基线购买率、面额、核销率、退款率各±20%。用户后续Q2明确本轮只用10元券，优先约束覆盖旧面额扫描。此轮保留基线(.08/.12)、核销(.44/.66)、退款(.06/.09)各±20%，用首单金额比例均值(.56/.84)与标准差(.08/.12)作为合法的金额机制敏感性，另加成本预测乘子(.8/1.2)。这不等价于已经研究面额效应；正文必须说“固定10元券下的金额/成本敏感性”，不能把替代参数称为面额扫描。

每个扰动必须在机制诊断中证明所改字段被消费。例如金额均值应改变首单比例分布，基线目标应改变真实购买曲线，预测成本偏差只改预测约束不改实际成本。诊断可以不要求策略结论变化；禁止预设“结论方向必须稳定”再调参达成。未触发机制差异的空扫描判为实现错误。
