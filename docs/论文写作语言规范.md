# 论文写作语言规范

> 维护时间：2026-11-01 00:40（北京时间）。
> 本文档约束**论文正文**（`paper/v3b/`）的语言。仓库里的工程文档不受此约束。

## 一、禁止版本语言

论文是独立成篇的研究，不出现自身的历史版本：

- ❌ `v2`、`v3`、`v3b`、`旧稿`、`前稿`、`本版`、`重构`、`改判`、`此前版本`
- ❌ `本次修订`、`相较上一版`、`保留/删除/新增`（指自身上下文的增删）
- ✅ 直接写研究内容本身。需要说明"为什么这样做"时，讲**设计与证据**，不讲编辑历史。

## 二、禁止审计语言

下列词属于工程纪律，留在仓库文档里，**不进论文正文**：

| 禁用 | 改用 |
|---|---|
| 门禁、校验器、闸门 | 检验、判定准则 |
| 证据包、登记、登记号、复算 | 结果表、汇总（必要时才提"可复现"） |
| 通过 / 改判 / 判定边界（作为流程术语） | 成立 / 不成立 / 适用范围 |
| provisional、manifest、sha256、binding、快照 | （不出现；必要处写"冻结的输入"） |
| 脚本编号（`42 号`）、`out/`、`outputs/tables/xxx.csv` | "结果表"或省略 |
| 口径红线 R1/R2/R3 | 口径约定（正文叙述，不编号） |
| "本文不宣称"、"须同时引用局限" | 直接陈述结论与其条件 |

**允许保留的最小复现信息**：图注/表注中的"层级 + 重复次数 R + 样本量 n"。这是实验条件，不是审计语言。

## 三、语气规则

1. **陈述发现，不陈述流程**。"在 L3 上，未调整的估计高出 6 倍"而不是"我核对了 L3 的表"。
2. **结论带条件**。凡跨设定推广，必须写清成立范围；不允许"一般认为"。
3. **不利结论照写**。失效、反例、与预期不符的结果是主要内容，不淡化、不省略。
4. **不用自我评价词**：严谨、全面、深入、创新性强——用事实替代。
5. 少用"我们"，统一用"本文"。
6. 一段一义：每段开头给判断，随后给证据，末尾给含义。

## 四、数字规则

1. **只写能回指结果表的数**。正文不出现无法追溯的数值。
2. 估计必带区间或 MC 标准误；比率必带分母。
3. 单次代表实现（单 rep）必须写明"单次代表实现"，不得与多次重复的结论并列表述。
4. 低重复次数的结果（如边界格的 30 次）必须逐格标 R，且不与高重复结果排序比较。
5. 百分点与百分比不混用：`pp` 用于差值，`%` 用于相对变化。

## 五、结构与图表

1. 图优先组图（多面板），一张图讲一件事的多个侧面。
2. 图注：标题给结论，轴带单位，末行给实验条件。
3. 每章开头一段"本章要回答什么"，结尾一段"本章结论的边界"。
4. 章节编号到三级；三级标题下不再分小标题。
