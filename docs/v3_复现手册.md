## 7. 复现的边界（读之前必须知道）

1. **哈希绑定是"当时"的**：`out/g03_snapshot/snapshot_binding.json` 记的是运行启动时刻的源码字节。
   之后任何改动都会让它与实时源码不一致——这不是 bug，是门禁在工作。
2. **有些 sha256 含运行标识**：观测表的 `dataframe_sha256` 里含 `run_id`，跨运行比对必须先排除该列（AGENTS §11.3）。
3. **同一份数据不会有第二个独立样本**：同 `master_seed` + 逐 rep 派生 ⇒ 同配置重跑逐字节相同；
   要检验漂移影响必须换种子（另立实验）。
4. **Tier1 与 Tier2 的重复数不同**（core `R=500`／Tier2 `R=30`），区间宽度不可直接并列比较。
5. **盘上的 json 会过期**：`out/scratch/*.json` 里的页数、占比描述的是**那一次**构建。
   20:23 就踩到过——`audit43.json` 是 10 页/45.27% 的旧跑，而当前构建是 12 页/59.38%。引用前重跑。
6. **`out/` 不入库**：任何别人需要复算的材料必须经 20/40/41 导出到 `outputs/evidence/` 并登记，
   否则换个 checkout 就不存在（19:30–20:25 因此把 41/48/49/50/51/52 号从 `out/` 提进 `scripts/`）。
