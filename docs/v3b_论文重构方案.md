## 1. 叙事主线（一句话）

> **在有限预算下，如何仅凭可观测数据决定"是否发券、发给谁、发多大面额"，
> 并证明策略创造的净增量利润及其适用边界？**

这条主线要回答四个递进的问题，每个问题对应一层：

| 层的提问 | 该层新增的麻烦 | 该层要给出的答案 |
|---|---|---|
| **L0**：机制最干净时，利润效应能不能被无偏估出来？ | 无（只保留零膨胀与重尾） | 估计量本身的正确性下限 |
| **L1**：加入真实金额链路与个体异质性后，CATE 与策略还成立吗？ | 购物车→首单→复购、券只对首单、异质性 | 异质性的可辨识程度、模型选择的实际影响 |
| **L2**：时间流逝与人群漂移后，结论会不会翻转？ | 分周、平滑漂移、人群构成变化、成熟延迟 | 结论的时间稳定性边界 |
| **L3**：当混淆不可观测时，方法还能走多远？ | 未观测混淆 λ_T、极端重叠、缺失混淆 | 失效的**定量**位置，而不是"能不能" |

**为什么要分四层而不是一次做完**：识别问题无法在真实数据上判定"谁对谁错"。
分层的作用是把"哪一条假设被放松"与"结论在哪一步失灵"一一对应起来——
**每一层只放松一条**，于是失效可以被归因，而不是笼统地"有偏"。

### 第三部分 结果与分析（目标 ≥50% 正文，25–40 页）

- `3.1` 流程校准：先把"机器不会自己制造显著"钉死
  - `3.1.1` 1000 次 AA：合并 FPR 0.046，CP [0.0339, 0.0609]

  - `3.1.3` 负对照：购买率给 α（0.08）、利润给功效（1.00），二者不可互换
  - `3.1.4` 设计 MDE 与实测功效曲线（15 格 × 100 次）
- `3.2` **L0：机制最干净的一层**
  - `3.2.1` ATE 500 次的偏差与精度（0.2434）
  - `3.2.2` 零膨胀重尾对样本量的含义：约束者不是主指标

- `3.3` **L1：真实金额链路与异质性**
  - `3.3.1` ATE 与 CATE：R=200 的模型对照（选模分布 CF 105 / S 71 / DR 12 / 常数 7 / T 5）

- `3.4` **L2：时间与人群的变化**

- `3.7` 策略层：预算、求解器与成本模型

  - `3.7.2` 三种口径的超支代价（两个分母都报）

## 4. 写作纪律（不可妥协）

1. **数字只来自已落盘的表**，每个数字在正文可回指 `outputs/tables/*.csv`；沿用 `v3_h04_claim_registry.csv` 的登记号。
2. **"通过"的含义限定**：记录准确、断言范围正确，**不等于**真实业务有效、不等于可部署。
3. **Tier2（R=30）数字不得与 Tier1（R=500）并列排序**，必须逐格带 R 与 MC SE。
4. **单 rep 结论（E01/E02/F01）必须标注"单代表 rep"**，不得混入正式 R 的表述。
5. **失效条件必须与证据一一对应**，不允许"一般认为"式表述。
6. 新稿写在 `paper/v3b/`，**不改动 `paper/v3/`**（已通过验收的版本留在原处）。
7. 完稿后跑项目自带门禁：`scripts/42_claim_number_gate.py`、`43_long_draft_audit.py`、`07_check_consistency.py`、`44_citation_check.py`。
