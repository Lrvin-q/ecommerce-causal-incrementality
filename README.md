# 电商营销策略的因果评估与增量利润优化

> **数据来源：合成数据 / 已知 DGP（非真实企业数据）。**
> 本项目用**已知微观生成机制**的模拟器构造数据，再用分析方法去估计，把估计值与真值对比，
> 检验方法是否可信、在什么条件下失效（simulation-based validation）。

## 项目要回答的核心问题

> 在明确的预算与风险约束下，这项营销策略究竟创造了多少净增量贡献利润？我们凭什么相信这个数字？

业务场景：某电商平台"加购未支付"用户首单转化率偏低，运营有固定营销预算，
需决策 **是否发券、发给谁、发多大面额**。

**唯一主指标**：每位符合条件用户的**净增量贡献利润**
`τ_Π(X) = E[Π(1) − Π(0) | X]`
转化率增量、增量 GMV、券核销率、退款率仅作诊断，不用于主决策。

## 口径红线（违反即结果作废）

1. **退款订单不得剔除**，分析单位是随机分配的**全部用户**。
2. **两个窗口分开**：转化 7 天 / 利润成熟 30 天，所有用户等长。
3. **券成本只扣一次**：`Π^net` 已含，策略价值 `V(π)` 不再二次扣除；预算约束独立存在。
