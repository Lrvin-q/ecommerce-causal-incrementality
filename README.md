## 这项研究回答什么

有限预算下，运营要在"是否发券、发给谁、给多少"之间取舍。常见做法是训练模型预测谁更可能购买、再按预测排序投放。这套做法的隐含前提是——**估计出的个体效应足够可信，以至于按它排序能带来增量利润**。

本研究不假设这个前提成立，而是把它拆成四层分别检验：每层只在前一层基础上放松一条假设，使"哪一步失灵"可以被指认，而不是笼统得到一句"方法有效/失效"。

关键在于：在自建的数据生成过程里，**真值由解析式直接给出**。因此每个偏差都能被计算出来，而不是只能在不同估计量之间比一致性。

| 层 | 放松的假设 | 该层回答的问题 |
|---|---|---|
| **L0** | 最理想的基线：分配与结果无关、效应与成本同质 | 估计量本身有没有问题 |
| **L1** | 引入真实金额链路与个体异质性 | 平均无偏能否转化为个体可用 |
| **L2** | 引入时间漂移与人群构成变化 | 结论是否依赖评估窗口 |
| **L3** | 引入不可观测因子 | 混淆能偏多远、失效可检测吗 |

## 四条主要发现

**一、流程本身是校准的，但校准不等于有功效。**
1000 次零效应重复的合并假阳性率 **0.046**（Clopper–Pearson 95% 区间 [0.0339, 0.0609]），标准误校准比 0.987–0.995。流程不会自己制造显著结果——但它也测不出太小的效应。

**二、前三层的平均效应无偏，L3 不是；而 L3 的偏差来源是可算的。**
解析真值与估计的偏差分别为 **−0.51%、+0.53%、+0.80%**。L3 差 1.433 元/人，按定义可精确分解为：

$$\underbrace{1.6468}_{\text{朴素差}}=\underbrace{0.2112}_{\text{ATT}}+\underbrace{1.4357}_{\text{选择项}}$$

两项之和与直接计算的朴素差逐位吻合。也就是说：**仅凭可观测的选择，就足以让未调整估计偏离 6 倍**，无需引入任何未观测混淆。

**三、没有证据表明模型驱动的定向优于一条两行的业务规则。**
在配对的 200 个独立重复上，业务规则（新客优先、再按购物车金额）在三个预算档分别高出贪心策略 **0.036 / 0.054 / 0.032** 元/人，按重复聚类后 t ≈ −20。但两处聚合口径之差（0.064）比这个幅度还大，因此只主张"方向"、不主张"量级"。

原因在个体层面：表现最好的因果森林，其估计 CATE 与真值 CATE 的相关系数只有 **0.10**，校准斜率 0.75，逐点误差 6.1 元/人（约为平均效应的 22 倍）。

**四、真正的约束是成本与口径，不是排序精度。**

- **盈亏平衡**：购买率增量需超过 **3.31 个百分点**才能覆盖券成本，而设计效应是 5 个百分点——安全垫仅 **1.51 倍**
- **预算临界值**：$B^{*}=f\cdot r\cdot p_1\approx$ **0.83 元/人**；人均预算远低于它是"口径"问题，不是"算法"问题
- **护栏**：退款率差在分配人群口径下单侧上界 0.4964–0.4992（界值 0.5），只是擦线通过；**换分母必须连界值一起换**
- **成本预测**：定向策略实际支出比预测高 **5.6%**（179/200 次为正），是系统性偏差

## 这份研究的边界

诚实地说清"不做什么"，比强调"做了什么"更重要：

- **只有单一券面额**（10 元，作为外生条件）。本研究不研究面额优化，也不能外推到最优面额
- **全部为合成数据**。所有绝对水平都是在一套设定机制里标定出来的，不构成对任何真实企业的效果承诺
- **可迁移的是"线与斜率"，不是绝对值**。例如"预期效应是盈亏平衡点的几倍"这个问法、$B^{*}=f\cdot r\cdot p_1$ 这个式子、以及"口径必须连分母和界值一起定义"这条纪律
- **结论依赖机制形状**。"业务规则胜过模型"成立的前提是：效应恰好集中在少数已记录特征上。若效应分布在大量弱特征上，结论可能相反

论文附录 K 专门列了 8 条**引用本文结论时的常见误用**（例如把某个标定量乘上用户数写进预算、用全期平均效应决定一个正在衰减的投放是否续投），建议引用前先看那一节。
