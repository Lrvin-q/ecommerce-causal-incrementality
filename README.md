# 电商营销策略的因果评估与增量利润优化

> 数据版本：v2（含复购路径，5% 用户产生第二单）。v1→v2 的关键数字变化见 [reports/00_项目总报告.md](reports/00_项目总报告.md) 附录 D。

> **数据来源：合成数据 / 已知 DGP（非真实企业数据）。**
> 本项目用**已知微观生成机制**的模拟器构造数据，再用分析方法去估计，把估计值与真值对比，
> 检验方法是否可信、在什么条件下失效（simulation-based validation）。

## 项目要回答的核心问题

> 在明确的预算与风险约束下，这项营销策略究竟创造了多少净增量贡献利润？我们凭什么相信这个数字？

业务场景：某电商平台"加购未支付"用户首单转化率偏低，运营有固定营销预算，
需决策 **是否发券、发给谁、发多大面额**。

**唯一主指标**：每位符合条件用户的**净增量贡献利润**
`τ_Π(X) = E[Π(1) − Π(0) | X]`
转化率增量、增量 GMV、券核销率、退款率仅作诊断，不用于主决策。

## 可复现性等级（如实说明）

```powershell
python scripts\run_all.py --round all      # 约 10 分钟，重跑全部数据/结果/图
```

连续运行两次的实测结果（v2 数据，最近一次：618 秒跑完四个脚本）：

| 层级 | 结论 |
|---|---|
| **随机性** | ✅ 完全确定。所有随机流由 `(master_seed, stream, index)` 派生，新增流不扰动旧流 |
| **数据与主结果** | ✅ 完全一致。五张关系表、45 张结果表中的 **39 张逐字节相同**（含 ITT/护栏/λ 扫描/策略对比） |
| **少数浮点汇总列** | ⚠️ 4 张表（`r2_cate_*`、`r3_greedy_gap`）末位有差，**相对误差 ≤ 5.2×10⁻¹⁵** |

那几处差异来自 **LightGBM / BLAS 多线程累加的求和顺序不固定**（浮点加法不满足结合律），
不是逻辑不确定。以相对误差衡量是 1.4×10⁻¹⁶～5.2×10⁻¹⁵（机器精度量级）；
绝对差最大 3.6×10⁻¹² 出现在 25,151 量级的求和列（相对 1.4×10⁻¹⁶）。

> 刻意写明这一点：如果把"逐字节一致"写成结论，那是不诚实的。
> 真正的可复现性承诺应该是可量化的误差界，而不是一句断言。

## 核心结论

| 问题 | 答案 |
|---|---|
| 券该不该发？ | 该发，但**必须定向**。随机发券每 1 元只赚回 **0.730 元（亏钱）**，定向赚回 **2.085 元** |
| 定向离理论最优多远？ | 达真值贪心解 **86.1%**（真值最优 2.420 元/元） |
| 结论可信吗？ | 重复 200 次覆盖率 **0.945–0.950**（目标 0.95）；四参数 ±20% 扫描 **12/12 方向稳定** |
| 最大风险是什么？ | **护栏的分母决定符号**（全用户 +0.36pp / 已下单 −0.36pp），条件口径功效仅 0.194；且观察性数据在轻度混淆（λ=0.25）下就失效 |

## 口径红线（违反即结果作废）

1. **退款订单不得剔除**，分析单位是随机分配的**全部用户**。
2. **两个窗口分开**：转化 7 天 / 利润成熟 30 天，所有用户等长。
3. **券成本只扣一次**：`Π^net` 已含，策略价值 `V(π)` 不再二次扣除；预算约束独立存在。
